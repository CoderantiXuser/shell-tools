## LLM Tools

Tools for diagnosing and optimizing a system for running Large Language Models (LLMs).

*   **`LLM/llm_sys_id.sh`**: A diagnostic tool that gathers information about the system's hardware and software relevant to running LLMs. (requires sudo)
*   **`LLM/llm_sys_opt.sh`**: An interactive script for optimizing a system for LLMs, including package installation, CPU configuration, RAM disk setup, and swappiness optimization. (requires sudo)
*   **`LLM/llm_sys_opt_rollback.sh`**: A template or example of a rollback script generated by `llm_sys_opt.sh`.

## Qt5 Development Lab

Scripts for setting up a Qt5 development environment for both C++ and Python.

*   **`QT5_dev_Lab/qt5addons.sh`**: Sets up a complete Qt5 development environment by installing compilers, debuggers, Qt Creator plugins, and other tools. (requires sudo)
*   **`QT5_dev_Lab/qt5addons2.sh`**: A more streamlined version of `qt5addons.sh` for setting up a Qt5 development environment. (requires sudo)
*   **`QT5_dev_Lab/qt5pythonprep.sh`**: Sets up the environment for Python-based Qt development by installing PyQt5 and other useful modules. (requires sudo)
*   **`QT5_dev_Lab/qt5setup.sh`**: A master script for the entire Qt5 setup. (requires sudo)

## Advanced Tools

Scripts for analyzing Python code.

*   **`advanced/PyAnalyzer/main_v3.8.1.sh`**: A sophisticated Python code analyzer that uses Abstract Syntax Trees (AST) to generate detailed reports.
*   **`advanced/pro_synt.sh`**: A simpler Python code analyzer that focuses on resolving and listing imported modules.

## Git Tools

*   **`git/auto-git-repo-push.sh`**: A comprehensive, interactive tool to automate initializing a Git repository and pushing it to a remote.
    *   **Features**:
        *   `--guide` mode for step-by-step assistance.
        *   `--dry-run` mode to preview commands without executing them.
        *   Interactive prompts for commit messages and remote URLs, with smart suggestions.
        *   Robust authentication flow for both SSH and Personal Access Tokens (PATs).
        *   Clear logging of all git commands being executed.
*   **`auto-git-repo-push.sh`**: Note: This script has been removed to avoid duplication. The official script is now in the `git/` directory.

## Network Scripts

Scripts for analyzing and resetting network configurations.

*   **`network_scripts/net_man_analysis.sh`**: A very detailed network analysis script that gathers a lot of information about the system's network configuration and stores it in an associative array. (requires sudo)
*   **`network_scripts/net_mon_and_reset.sh`**: A powerful script for resetting network configurations. It includes the deep analysis function from the previous script and adds a function to reset interfaces to DHCP. (requires sudo)

## System Administration & Diagnostics

A collection of scripts for system diagnostics and administration.

*   **`system/sys-audio_analysis.sh`**: A comprehensive audio diagnostic script. (requires sudo)
*   **`system/sys-bt-audio-diag.sh`**: An extremely detailed diagnostic script for Bluetooth and audio issues. (requires sudo)
*   **`system/sys-device-analyzer.sh`**: A script that gathers comprehensive information about the system's hardware and drivers. (requires sudo)
*   **`system/sys-display_recovery.sh`**: A script designed to diagnose and repair common display and login issues on Linux systems. (requires sudo)
*   **`system/sys-dmesg_logger.sh`**: A script that collects various `dmesg` outputs to help diagnose kernel-related issues. (best run with sudo)
*   **`system/sys-linux_repos_repair.sh`**: A script for analyzing and repairing common issues in Linux APT repository configurations. (requires sudo)
*   **`system/sys-logs_codex_generator.sh`**: A script that collects, organizes, and optionally compresses system log files into a structured directory. (requires sudo)
*   **`system/sys-perf-diag.sh`**: A comprehensive performance diagnostic tool. It runs various checks on CPU, memory, disk, and network, and then calculates a performance score. (best run with sudo)
*   **`system/sys_usr-groups.sh`**: An interactive script for managing users and groups on a Linux system. (requires sudo)
*   **`sys-perf-diag.sh`**: Note: This is a duplicate of the script in the `system/` directory.
*   **`sys_usr-groups.sh`**: Note: This is a duplicate of the script in the `system/` directory.

## Voice & Speech Synthesis

Scripts for configuring text-to-speech systems.

*   **`voice/speech_dispatcher/spd.sh`**: An interactive script for configuring the Speech Dispatcher text-to-speech service. (requires sudo)
*   **`voice/voice_conf.sh`**: A script for configuring various text-to-speech systems, including RHVoice, Speech Dispatcher, and Festival. (requires sudo)

## Standalone Utility Scripts

A variety of scripts for different purposes.

*   **`RAM_based_cpp_compilation.sh`**: A script for compiling the `whisper-cpp-python` library with specific optimizations, using a RAM disk to improve performance and reduce wear on storage. (requires sudo)
*   **`crontab-me/crontab`**: A crontab file to run `mystartup.sh` on reboot.
*   **`free_space.sh`**: A system diagnosis script that gathers a wide range of information, including system info, large files, running processes, network activity, logs, and disk usage, and saves it to a log file. (best run with sudo)
*   **`gemini-cli.sh`**: A script for installing and configuring the Gemini CLI tool, including setting it up to autostart. (requires sudo)
*   **`mystartup.sh`**: A script that configures a systemd service to run a series of commands on startup, including starting Bluetooth, a Bluetooth manager, and a Python script. (requires sudo)
*   **`ram_run.sh`**: A script for running applications in a RAM-based sandbox to improve performance and security. (requires sudo)
*   **`sunflower.sh`**: A simple script that runs the `sunflower` command with `sudo`. (requires sudo)
*   **`talon_env_check.sh`**: A script for checking if a system is correctly configured to run Talon Voice, a voice-controlled accessibility tool.
*   **`usermissmatch.sh`**: A diagnostic script for troubleshooting user mismatch issues between VSCode and GitHub.
